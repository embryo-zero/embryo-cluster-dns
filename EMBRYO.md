# Embryo Cluster DNS

Embryo Cluster DNS is Embryo-Zero's fork of [coredns](https://github.com/coredns/coredns) (7d96e41, commit 7d96e41). It does DNS for services inside the cluster.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
